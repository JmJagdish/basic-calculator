# 🧮 Calculator

A simple, responsive, and user-friendly calculator built using **HTML, CSS, and JavaScript**. The calculator performs basic arithmetic operations through a clean and modern interface and works directly in any web browser.

## 💻 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/JmJagdish/basic-calculator.git
```

2. Open the project folder:

```bash
cd basic-calculator
```

3. Open `index.html` in your browser.

That's it! No server or additional dependencies are required.
